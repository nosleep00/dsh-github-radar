## 1. 要做什么（一句话）

一个 DSH 插件：读当前会话在做什么 → 去 GitHub 搜相关开源项目 → 在**右栏侧边栏**里用卡片展示，每张卡带一句**中文说明**和**为什么推荐**；纯被动，不往模型上下文里塞东西。

## 2. 验收标准（DoD）

### 用户视角（缺一不可）
1. 打开任意会话 → 右栏「+」或引导页里能看到入口 → 点开出现「GitHub 雷达」页签，每个会话一份、互不干扰。
2. 聊几轮后（或点刷新），出现 **5 张卡片**；每张有：仓库名、语言、star、最近更新时间、**中文一句话**、**为什么推荐**、三个操作（打开 / 复制装法 / 不感兴趣）。
3. 没有 token、匿名状态可用；被限速时出黄条提示自动重试，不弹错误框。
4. 断网时回放上次缓存，面板显示「离线 · 缓存于 X 前」。
5. 「仅看中文项目」开关打开后，只剩中文社区/中文说明的项目，并提示「结果可能变少」。
6. 设置项可见可改，改完立即生效（不重启）。

### 工程视角
1. `pnpm typecheck && pnpm test && pnpm build` 全绿。
2. 宿主侧抓取全部经过单个队列（有并发上限），任何网络错误都被捕获并转成 UI 状态，**无未捕获 Promise**。
3. 面板刷新在会话事件流里**去抖 75s**，同样内容 hash 不重复请求。
4. Git 工作区干净、每个 STEP 有 commit、CHANGELOG 有 0.1.0 条目。

## 5. 数据模型（先定死，后面都按它写）

```ts
// src/host/types.ts  —— 客户端用 import type 引用，不得运行时 import
export type RepoCard = {
  fullName: string          // "astral-sh/uv"
  htmlUrl: string
  descriptionEn: string     // 原文
  topics: string[]
  language: string | null
  stars: number
  pushedAt: string          // ISO
  archived: boolean
  zh: string                // L1 模板生成，L2 到达后替换
  zhSource: 'template' | 'llm'
  why: string               // 命中说明，如「你提到 pip install 很慢」
  install: string[]         // ["uv tool install …"]，可为空
}

export type RadarSignal = {
  sessionId: string
  keywords: string[]        // 最多 5 个
  errorText?: string        // 报错片段，最多 200 字符
  languages: string[]       // 由设置的语言偏好合并
  turnedAt: number
}

export type RadarState = {
  status: 'idle' | 'loading' | 'ready' | 'empty' | 'rateLimited' | 'offline' | 'error'
  cards: RepoCard[]
  updatedAt?: number
  retryAfterMs?: number     // rateLimited 时
  quota?: { remaining: number; limit: number; resetAt: number }
  notice?: string           // 离线/降级说明
  errorMessage?: string
}
```

**持久化**（`$DSH_HOME/plugin-data/dsh-github-radar/`，具体根路径 `【需核实 storage.md】`）：
- `cache.json`：`{ [queryHash]: { at: number, cards: RepoCard[] } }`，保留最近 40 条、总大小 < 2MB。
- `feedback.json`：`{ dismissed: string[], clicked: Record<string, number>, stars: Record<string, number> }`。
- `summaries.json`：`{ [fullName+description+locale]: { zh, at } }`，上限 2000 条。

## 7. 阶段 A：准备（S00–S03）

### S00 修好沙箱写权限 ★最高优先级

**症状**：任何 pwsh 命令都返回 `Error: SetNamedSecurityInfoW failed (Win32 5): grantWrite(<repo>)`。

**动作（二选一，优先 A1）**
- **A1（推荐，一次到位）**：请用户把本会话权限切到「完全访问 / danger-full-access」，或对该命令单独批准。批准后重跑一条自检：
  `pwsh -Command "New-Item -ItemType Directory -Force <repo>\.sandbox-test | Out-Null; Test-Path <repo>\.sandbox-test"` → 期望 `True`，随后删除该目录。
- **A2**：运行 DSH 自带诊断脚本（技能 `diagnose-windows-sandbox-acl`）：
  ```
  <home>\AppData\Local\Temp\dsh-acl-skill-Z2q8TG\scripts\diagnose-windows-sandbox-acl.ps1
    -Path <repo> -AllowRoot E:\ -Out $DSH_HOME\acl-report
  ```
  需一次性非受限批准；跑完把报告摘要写进 `docs/进度.md`。

**验收**：`New-Item` 能在工作区成功建目录；`pnpm --version` 能跑。
**失败排查**：若 A2 报 ACL 继承问题，按报告建议修，不要自行 `icacls` 大范围改权限。

import { RadarPane } from './RadarPane'

export const name = 'dsh-github-radar:client'
export const inject = ['slots', 'sidebarRightTabs']   // locale 在 S22 加

export function apply(ctx: any) {
  ctx.effect(() => ctx.sidebarRightTabs.register({
    id: 'radar',
    kind: 'radar',
    title: () => 'GitHub 雷达',                 // S22 换成 t('radar.title')

  ctx.slots.inject('sidebar.right.pane.tab', () =>

}

## 9. 阶段 C：M1 — 真实推荐（S08–S14）

### S08 remote 接口 + 假数据打通

目标接口面（以 S02 核实后的写法实现）：

```
ctx.remote.radar.refresh(signal: RadarSignal): Promise<RadarState>
ctx.remote.radar.get(sessionId: string): Promise<RadarState>
ctx.remote.radar.dismiss(fullName: string): Promise<void>
ctx.remote.radar.subscribe?(sessionId): stream<RadarState>   // 有 stream 再上，没有就轮询 get
```

先返回 5 张写死的假卡（用 uv / pydantic / ripgrep / gum / tauri 的真实字段），验证 client→host→client 全链路。
**验收**：点面板刷新，卡片来自宿主且能显示中文模板（此时可硬编码中文）。

### S09 会话信号提取（客户端）

- 用 `useConversation` / `useChat`（`【需核实】` 具体 hook 名与返回形状，见 slots.md 的 hooks 清单）读最近消息。
- 规则：
  - 取最近 **3 条用户消息**，剥掉代码块与 URL，抽 2–5 个关键词（英文技术词优先：`pydantic`、`docker`、`rag` 等；中文需求词映射见附录 D）。
  - 正则抽报错：`/(Error|Exception|Traceback|error:)[^\n]{0,180}/`，取首次命中，截 200 字符。
  - **不上传原文**：只传关键词数组 + 报错片段。
- 去抖：`turnedAt` 变化 ≥ `refreshDebounceMs` 且 `keywords` 组成的 hash 变了才请求。
**验收**：`console.debug` 里能看到脱敏后的 signal（单测 `test/signals.test.ts` 覆盖关键词抽取与 hash）。

### S10 GitHub 客户端

- 端点：`GET https://api.github.com/search/repositories?q=...&sort=stars&order=desc&per_page=20`
- 头：`Accept: application/vnd.github+json`、`X-GitHub-Api-Version: 2022-11-28`、`User-Agent: dsh-github-radar/0.1.0`，有 token 时加 `Authorization: Bearer <token>`。
- 单飞队列：全局并发 1，最小间隔 2s（匿名）/ 1s（有 token）。
- 读 `x-ratelimit-remaining / limit / reset`（秒级 epoch）→ 写进 `RadarState.quota`。
- `403/429`：解析 `retry-after` 或 `x-ratelimit-reset`，返回 `rateLimited` + `retryAfterMs`，**不重试循环**。
- `5xx`：退避重试 1 次（1s），仍失败 → `error`。
- ETag：`If-None-Match`，命中 304 → 用缓存。
**验收**：`test/mock-github.test.ts`（本地 http server）覆盖 200 / 304 / 403 / 429 / 断网 五种路径。

### S11 查询构造器

```ts
buildQuery(signal) -> string[]
```
- 每个关键词一条查询：`${kw} in:name,description,topics stars:>=${minStars}`（关键词含空格时加引号）。
- 报错文本：`"${excerpt}" in:readme`（GitHub 不支持 quoted phrase 时降级为取前 3 个词 AND）。
- 语言偏好：追加 `language:Python` 等（多选则每个语言一条，合并去重）。
- `chineseOnly`：见 S20（查询层加 `topic:chinese` 变体）。
- 硬限制：一次刷新最多 3 条查询、总候选 ≤ 60 条。
**验收**：单测覆盖「只有关键词」「关键词+报错」「空信号→返回空数组」「中文关键词映射成英文」。

### S12 排序与去重

```
score = 0.45*norm(stars) + 0.25*recency(pushedAt) + 0.20*langMatch + 0.10*topicMatch - penalties
```
- 排除：`archived`、已 dismiss、已出现过的 fullName。
- 每条附 `why`：来源优先级「命中报错 > 命中关键词 > 语言匹配」。
- 多样性：同 owner 最多 1 条；最多取 `maxCards`（默认 5）。
**验收**：单测用固定候选集断言排序与 why 文案。

### S13 L1 中文词典与模板

- `src/host/zh.ts`：`TOPIC_ZH: Record<string, string>`（先 40 条，最终 ~200）、`LANG_ZH`、`TEMPLATE`。
- 生成规则：`${topics 中文拼接，最多 2 个}${语言 ? ' · ' + 语言 : ''}${stars>=1000 ? ' · ' + 星标 : ''}` + `一句话：${description 去品牌词后的中文模板}`。
- 保底：无 topic 时用「一个用 ${language} 写的开源项目，${stars} 星」。
**验收**：单测覆盖 5 种输入（有 topics/无 topics/中文 description/超长 description/空 description）都不产出 `undefined`。

### S14 卡片与面板状态机

- `RadarPane` 按 `RadarState.status` 渲染：骨架 / 空态 / 黄条（限速）/ 灰条（离线）/ 错误（带重试）。
- `RadarCard`：三段结构 + 三操作（打开走 `ctx.sidebarRight.openTab('browser', { params: { url } })` `【需核实】browser kind 的参数名`；复制装法用 `navigator.clipboard`；不感兴趣调 remote）。
**验收**：对着 `mockup-radar.html` 逐项比对；控制台无 React key 警告；卡片列表 5 条不滚动即可读完。

## 10. 阶段 D：M2 — Beta（S15–S21）

### S15 缓存与离线回放
- 查询 hash 命中且 `age < 30min` → 直接返回，不发网络请求。
- 网络失败 → 用 `cache[queryHash]` 回放，`status: 'offline'`，`notice: '缓存于 N 分钟前'`。
- 缓存写入放在 `【需核实 storage.md】` 的插件数据目录；写入用临时文件 + rename 保证原子。

### S16 限速 UI
- 面板顶部黄条：「GitHub 暂时限速，{N} 秒后自动重试」+「怎么配」；倒计时按 `retryAfterMs` 走，到点自动重试一次。
- 底部额度条：`剩余 x/limit`（有 token 显示 5000）。
- 禁止：自动无限重试（最多 1 次自动重试）。

### S17 代理与网络
- `allowNetwork=false`：完全不发请求，只回缓存；设置页文案说明。
- `proxyUrl` 非空 → 走代理 `【需核实桌面版 fetch 的代理方式：Node undici ProxyAgent / 环境变量】`；同时 `process.env.HTTPS_PROXY` 兜底，设置页提供「忽略环境变量」开关。
- 失败顺序：直连 → 代理（若配）→ 缓存。

### S18 L2 AI 中文简介
- 触发条件：`enableAiSummary && 面板可见 && 有卡片 && 未被限速`。
- 一次请求 5 条：`ctx.llm.stream({ ... })` `【需核实 GenerateOptions 字段与如何取当前模型】`；prompt 固化在 `prompts.ts`，要求输出严格 JSON 数组。
- 校验：`JSON.parse` 成功、长度 ≤ 60 字、不含 URL、`fullName` 与原卡匹配；任一条失败只回退该条的 L1。
- 结果写 `summaries.json`（key = fullName + description + locale），卡片 `zhSource: 'llm'`，显示 `AI` 角标。
- **绝不阻塞首屏**：L1 先渲染，L2 异步 replace。

### S19 设置页
- 字段：`githubToken`（密码框 + 「测试连接」打 `/rate_limit`）、`enableAiSummary`、`languages`（多选：Python/TypeScript/Rust/Go/Java/C#/C++）、`chineseOnly`（默认关，描述里写「只保留中文社区项目，结果会变少」）、`minStars`、`maxCards`、`refreshDebounceMs`、`proxyUrl`、`allowNetwork`。
- 实现路径：`ctx.inject(['configEditor'])` 写 profile patch（0.2+），失败回退 `ctx.inject(['settings']).register(...)`（0.1.x），写法照抄 godot-bridge 的 `godot-bridge.mjs:119-171`。
- **token 存 Config 字符串**（v1）；v1.1 迁 `ctx.credentials`。

### S20 「仅看中文项目」的判定（开关打开时）
规则按成本从低到高，**任一命中即算**，并且要能被单测：
1. `topics` 命中集合：`chinese`、`chinese-language`、`中文`、`chinese-translation`、`zh-cn`。
2. `description` 中文字符占比 ≥ 30%。
3. （可选，前 10 条才做）拉 README 首 4KB，中文字符占比 ≥ 20%。
4. 召回补偿：同时并行发两条带 `topic:chinese` / `in:readme "中文"` 的查询，避免过滤后空手。
> UI 文案必须诚实：「仅看中文项目 · 覆盖范围较窄，可能少于 N 条」，空结果时给「关掉这个开关看看」按钮。

### S21 不感兴趣与冷却
- 点「不感兴趣」→ 写 `feedback.json.dismissed`，从列表移除，**30 天内不再出现**。
- 点击「打开」累计 `clicked`，用于 S12 的微调（同 owner/topic 加权 +0.05，上限 0.1）。
